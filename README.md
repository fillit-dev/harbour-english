# Harbour English

A simple marketing site for an English immersion stay in Wicklow Town — guests live in a highly rated Airbnb and spend each afternoon with Des, a fully qualified English teacher.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5173`).

## Deploy

The site is a static Vite build on Render (`render.yaml`). Push to `main` to redeploy.
